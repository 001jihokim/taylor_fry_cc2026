# taylor_fry_cc2026
UNSW x ASOC Taylor Fry Case Comp (T3 2026)

STEPS TO REPRODUCE CODE & OUTPUTS:

1. GIT PULL for the most recent version of the code 
    (make sure you are on the main branch)
    
2. Open 01_setup_eda_cleaning.R

3. Click SOURCE on the top-left of the file viewer 
    (This is to to run the code. 
      You can also SOURCE with echo to see the code on your console as it runs)
      
4. Repeat steps 2-3, now for 02_modelling.R

5. You will see that a temp_output folder has been created. 
    This is not tracked on GIT (.gitignore has this file to be untracked)
    
6. All data outputs are saved here.
